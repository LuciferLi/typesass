## 需求确认

实时字幕是一个独立于现有口述、翻译、随便问之外的新模式。用户按下快捷键后，应用进入“字幕监听模式”，开始采集音频输入并持续进行 ASR 识别。只要 ASR 返回可展示字幕，屏幕底部就显示实时字幕条；同时右上角展示可拖动的字幕历史列表。

第一版默认快捷键暂定为 `Control + Shift + S`，原因是现有口述模式已经使用 `Control + P`，翻译模式使用 `Control + T`，随便问模式使用 `Control + Space`，实时字幕需要避免和现有语音输入流程冲突。后续可纳入快捷键设置页统一配置。

## 功能目标

1. 用户可通过快捷键快速进入或退出字幕监听模式。
2. 字幕监听模式开启后，应用开始采集音频输入。
3. 音频输入目标包括麦克风声音和电脑系统播放声音；正式方案需要支持两路音频同时采集、对齐和混音后送入 ASR。
4. ASR 返回字幕后，屏幕底部出现半透明黑色字幕条。
5. 底部字幕条平时隐藏，有内容时才显示。
6. 底部字幕条宽度和高度随文字长度自动变化，类似视频播放器或会议字幕，不使用固定大面板。
7. 屏幕右上角展示半透明黑色字幕历史记录窗口。
8. 历史记录窗口可以拖动位置，并展示已经固化的字幕记录。

## 非目标范围

第一版不做以下能力：

1. 不做账号、云同步、多人协作或会议房间。
2. 不做说话人分离的强承诺；如保留麦克风和系统音频双轨，可为后续区分“我方/对方”预留数据基础。
3. 不做逐词级字幕效果承诺；第一版以句子或短片段级字幕为目标。
4. 不默认保存完整原始音频；如需要保存，必须单独增加用户开关和隐私说明。
5. 不把历史窗口做成完整笔记编辑器；第一版只展示、滚动、清空或复制。

## 交互流程

| 步骤 | 用户行为或系统状态 | 期望结果 |
| --- | --- | --- |
| 1 | 用户按下 `Control + Shift + S` | 进入字幕监听模式，开始采集音频 |
| 2 | 监听中采集到有效声音 | 本地按时间片段送入 ASR |
| 3 | ASR 返回临时字幕 | 屏幕底部显示实时字幕条 |
| 4 | 文字变长或换行 | 字幕条宽度和高度跟随内容自适应变化 |
| 5 | 当前句子被固化 | 当前字幕追加到右上角历史记录 |
| 6 | 一段时间没有新字幕 | 底部字幕条自动淡出或隐藏，历史记录保留 |
| 7 | 用户拖动历史窗口 | 历史窗口移动到新位置，并可持久化位置 |
| 8 | 用户再次按快捷键 | 退出字幕监听模式，停止音频采集和 ASR 请求 |

## 字幕监听模式

字幕监听模式是一个全局模式，不依赖 Hub 主窗口是否打开。进入后应保持后台运行，并通过独立悬浮窗口展示字幕结果。

### 模式状态

| 状态 | 含义 | UI 行为 |
| --- | --- | --- |
| `idle` | 未监听 | 底部字幕条隐藏；历史窗口可隐藏或保留上次状态 |
| `listening` | 正在采集音频 | 可显示轻量状态标识；底部字幕条等待 ASR 内容 |
| `transcribing` | 正在请求 ASR | 底部字幕条可继续展示上一段临时字幕 |
| `displaying` | 正在展示字幕 | 底部字幕条显示最新字幕 |
| `error` | 音频权限或 ASR 异常 | 展示轻量错误提示，不写入历史 |

### 快捷键规则

1. 默认快捷键为 `Control + Shift + S`。
2. 首次按下：进入字幕监听模式。
3. 监听中再次按下：退出字幕监听模式。
4. 如果快捷键注册失败，需要沿用现有快捷键诊断机制，在 Hub 中提示冲突原因并引导用户修改。
5. 后续实现时，实时字幕快捷键应进入统一快捷键配置表，和口述、翻译、随便问共用保存与注册逻辑。

## 底部实时字幕条

底部实时字幕条用于展示“当前正在说的话”或最近一次 ASR 返回的临时字幕。它不是固定面板，而是随文字内容动态变化的全局悬浮字幕。

### 展示规则

1. 默认隐藏。
2. ASR 返回非空字幕时显示。
3. 背景为半透明黑色。
4. 文本使用高对比白色，保证在浅色和深色桌面背景上都能阅读。
5. 字幕条水平居中，显示在屏幕底部安全区域上方。
6. 宽度随文本长度增长，但需要设置最大宽度，避免横跨整个屏幕。
7. 超过最大宽度后自动换行，高度随行数增加。
8. 建议最多展示 2 到 3 行，超出部分由新字幕替换或在历史窗口查看。
9. 一段时间没有新字幕时自动淡出或隐藏。

### 窗口行为

1. 使用透明、无边框、置顶窗口承载。
2. 字幕条本身不需要用户交互，建议设置为不抢焦点。
3. 字幕条不应遮挡用户当前输入焦点或打断其他应用操作。
4. 多显示器场景下，默认展示在当前活跃屏幕底部；若无法判断，则展示在主屏幕底部。

## 右上角字幕历史窗口

字幕历史窗口用于展示已经固化的字幕记录，不展示每一次会被修正的临时字幕。

### 展示内容

| 字段 | 说明 |
| --- | --- |
| 时间 | 字幕固化时间，可用短时间格式展示 |
| 文本 | 已固化字幕正文 |
| 来源 | 可选字段，后续可标记麦克风、系统音频或混合音频 |
| 状态 | 可选字段，标识普通记录、识别失败或被清空 |

### 交互规则

1. 历史窗口默认出现在屏幕右上角。
2. 背景为半透明黑色。
3. 窗口可拖动。
4. 拖动后记录窗口位置，下次进入字幕监听模式时恢复。
5. 历史列表支持滚动。
6. 第一版建议提供清空和复制入口；如时间不够，可先只做列表展示和拖动。
7. 历史窗口需要可交互，因此不能整体设置为完全点击穿透。

## 音频采集要求

实时字幕模式需要采集麦克风声音和电脑系统播放声音。由于 macOS 默认 WebAudio 只能稳定采集麦克风，系统声音需要通过原生层或虚拟音频设备实现。

### 第一版建议

1. 麦克风采集复用现有 WebAudio 录音能力。
2. 系统音频采集优先设计为原生层能力；如果实现成本过高，可先使用虚拟声卡方案验证字幕链路。
3. 内部保留麦克风轨道和系统音频轨道，完成时间戳对齐后再混音送入 ASR。
4. 即使第一版最终只混音给 ASR，也不要在数据结构上完全丢失来源字段，避免后续无法扩展说话人或来源标记。

### 系统音频验证方式

第一版测试系统音频采集时，可由用户在电脑里持续播放一段带人声的音乐、访谈或视频音频，然后开启字幕监听模式，观察底部实时字幕条是否出现字幕。该测试的第一判定目标是“系统播放声音能不能触发字幕出现”，不要求歌词或台词在冒烟测试阶段完全逐字准确。

该验证用于确认“电脑系统播放声音 -> 系统音频采集 -> ASR -> 字幕悬浮层展示”的链路是否打通。测试音源应优先选择有清晰人声或歌词的内容；如果播放的是纯伴奏、环境音或无人声音乐，ASR 可能不会返回可展示文字，此时不能直接判定字幕功能失败。

### 权限要求

| 权限 | 用途 | 说明 |
| --- | --- | --- |
| 麦克风 | 采集用户说话声音 | 现有录音流程已经需要 |
| 屏幕录制或系统音频捕获相关权限 | 采集电脑系统播放声音 | macOS 系统音频采集通常会依赖该权限体系 |
| 辅助功能 | 不一定是字幕必需 | 若仅展示字幕，不自动粘贴，则可不强依赖辅助功能 |

### 语音模式权限展示规则

转写、翻译、随便问、实时字幕的权限状态属于具体语音模式，不再作为首页或全局设置里的统一前置条件展示。每个语音模式卡片和模式详情页都需要展示本模式依赖的权限项，权限项包含名称、当前状态、勾或叉图标、状态说明和“去设置/查看”入口。

用户点击任一权限项时，应用弹出权限说明弹窗，说明该权限为什么被当前模式需要、应该如何开启，以及一个主按钮跳转到对应设置位置。麦克风权限跳转 macOS 麦克风隐私设置，辅助功能权限跳转 macOS 辅助功能设置，API Key、快捷键和系统声音来源跳转到应用内对应配置控件。用户通过快捷键或模式启动按钮进入某个语音模式时，如果缺少该模式必需权限，应用需要给出“请设置 XXX 权限”的提示，并自动打开 Hub 的对应模式详情和权限说明弹窗。

| 模式 | 权限项 | 缺失时行为 |
| --- | --- | --- |
| 口述 | API Key、麦克风、辅助功能、快捷键 | 阻止开始录音，提示设置缺失权限并进入口述详情 |
| 翻译 | API Key、麦克风、辅助功能、快捷键 | 阻止开始录音，提示设置缺失权限并进入翻译详情 |
| 随便问 | API Key、麦克风、快捷键 | 阻止开始录音，提示设置缺失权限并进入随便问详情 |
| 实时字幕 | API Key、麦克风、系统声音来源、快捷键 | 阻止字幕监听或提示配置系统声音来源，并进入实时字幕详情 |

## ASR 调用策略

实时字幕不能只等用户停止说话后再调用 ASR。第一版应采用“固定时间切片 + 停顿固化”的策略。

1. 监听中持续采集 PCM 音频。
2. 每隔固定时间切出一个音频片段送入 ASR，例如 `1.2s - 2s`。
3. 每个片段保留 `300ms - 500ms` 重叠区，降低切断词语导致的识别错误。
4. ASR 返回后先作为底部临时字幕展示。
5. 检测到明显停顿后，将当前句子固化并写入历史窗口。
6. 如果用户长时间连续说话没有明显停顿，需要设置强制切段上限，例如 `6s - 10s`，避免一直不返回字幕。
7. 固化字幕时需要做相邻片段去重，避免重叠音频导致重复文字。

## 数据流

```text
快捷键开启字幕监听
-> 麦克风音频采集
-> 系统音频采集
-> 双轨时间戳对齐
-> 混音或分轨缓存
-> 固定时间切片
-> 调用 Mimo ASR
-> 返回临时字幕
-> 底部字幕条展示
-> 停顿或强制切段后固化
-> 写入右上角历史窗口
```

| RTS-002 | 快捷键退出模式 | 监听中再次按快捷键后停止采集并停止发送 ASR 请求 |

| RTS-006 | 非固定大面板 | 底部字幕条不以固定大窗口展示，不长期占用屏幕底部大面积空间 |

| RTS-010 | 短暂停顿不中断 | 用户短暂停顿时不错误退出监听，也不导致字幕链路卡死 |

## 待澄清问题

1. 历史窗口默认是否一直显示，还是只在有历史记录后显示。
2. 历史窗口第一版是否需要“复制全部”和“清空”按钮。
3. 底部字幕在无新内容后自动隐藏的时间，建议默认 `3s - 5s`。
4. 是否需要为麦克风和系统声音分别展示来源，还是第一版只展示混合字幕。
5. 系统音频采集第一版是否接受虚拟声卡方案作为过渡。
6. 多显示器环境下，字幕跟随鼠标所在屏幕、前台应用所在屏幕，还是固定主屏幕。
