# Typeless MVP 复刻记录

## 第一版目标

先完成最小可用闭环，不做完整商业产品复刻：

| 能力 | 第一版状态 | 说明 |
| --- | --- | --- |
| Mimo 配置 | 已实现 | 支持 API Key、Base URL、ASR 模型、语言 |
| 录音 | 已实现 | 使用 WebAudio 采集 PCM，并编码为 WAV |
| 停止后转写 | 已实现 | 停止录音后立即调用 Mimo ASR |
| 耗时展示 | 已实现 | 展示录音时长、转写耗时、音频大小 |
| 结果复制 | 已实现 | 支持一键复制转写结果 |
| 全局快捷键 | 已实现 | 通过 `Control + P` 开始录音，再次按下停止并转写 |
| 托盘常驻 | 延后 | 下一版接入 Tauri tray |
| 悬浮窗 | 已实现 | 打开后后台待命；按 `Control + P` 时出现黑色胶囊录音条 |
| 自动粘贴 | 已实现 | 转写完成后写入系统剪贴板，并由 typesass 原生触发 Cmd+V 粘贴到当前输入位置 |
| 错误提示 | 已实现 | 失败时在屏幕顶部偏下显示错误气泡，几秒后自动隐藏 |
| 无焦点弹窗 | 延后 | 自动粘贴完成后一起补 |

## 技术选择

- 桌面壳：Tauri v2
- 前端：Vite + TypeScript + 原生 DOM
- 录音：WebAudio + WAV 编码
- 语音识别：小米 Mimo `mimo-v2.5-asr`
- 网页预览：本地 Node 服务转发 Mimo 请求

## 合规边界

本版本只按 Typeless 的交互行为做功能级参考，不复制 Typeless 源码、样式资产、品牌素材或专有文案。

## 验证方式

第一版验证重点：

1. `npm run build` 前端编译通过。
2. `npm run preview:web` 能打开本地预览页。
3. 填入 Mimo API Key 后，录音停止可以返回转写文字。
4. 页面能展示转写耗时并复制结果。

当前机器已安装 Rust/Cargo，可直接构建 Tauri 原生壳。

## Flow7 验收结论

- 风险等级：L2。原因是本轮涉及录音、第三方 ASR、全局快捷键、剪贴板和自动粘贴流程。
- 闭环状态：网页预览模式和 Tauri 桌面模式均已形成可验证闭环；`.app` 已重新构建并启动；悬浮胶囊、顶部错误气泡、快捷键和 typesass 原生自动粘贴已接入；已处理辅助功能列表已开启但运行时误判未授权的问题。
- Rule 合规：没有修改公共包；未写入 API Key；TypeScript 未使用 `any`；核心类型和函数已补中文注释；项目级 Cargo 镜像配置仅用于加速当前仓库依赖下载。
- 未覆盖项：真实麦克风录音和 `Control + P` 全局快捷键需要用户手动试；托盘常驻、无焦点弹窗属于下一版范围；自动粘贴需要 macOS 辅助功能权限配合完整验证，未授权时可直接手动 `Cmd+V` 使用剪贴板里的转写结果。
