# 许可证与合规边界

## 许可证结论

Typeless 是商业闭源产品或未公开源码授权。typesass 只以产品行为作为参考，不复制任何可复用源码或商业素材。

## 允许复刻

- 快捷键唤起录音和停止录音。
- 悬浮录音控件的行为语义。
- 转写后自动粘贴到当前输入框。
- 没有焦点时展示结果并支持复制。
- 历史、词典、设置、统计、翻译、随便问等功能结构。
- 错误、空状态、权限提示等交互语义。

## 禁止搬运

- Typeless 源代码、打包资源、CSS、图片、图标、品牌字体和专有素材。
- Typeless 独有长文案、营销文案和隐私政策原文。
- 用户本机历史记录的具体私人内容。
- Typeless 服务端协议、付费系统、账号系统的内部实现。

## 上线风险

- 如果后续用于商业上线，需更换 typesass 自有品牌、图标、隐私说明和服务条款。
- 如果引入第三方 AI 服务，需要明确数据保留策略和用户授权提示。
- 如果保存历史和词典，默认应只本地保存；云同步需单独确认隐私与安全边界。
