# 测试策略

## 风险等级

L3。用户要求完整复刻，涉及多窗口、快捷键、录音、AI 服务、自动粘贴、历史和配置。

## 当前测试范围

- 静态检查：`npm run build`、`cargo fmt --check`、`npx tauri build --bundles app`。
- 安全检查：扫描 Mimo Key 是否落盘。
- Hub 页面：打开 Hub，检查首页、历史、词典、设置视图可见。
- 词典：新增词、搜索词、删除词。
- 历史：通过真实转写产生本地历史后，验证筛选、复制、删除；当前无历史时验证空状态与禁用按钮。
- 快捷键：默认 `Control+P` 进入口述；`Control+T` 进入翻译；`Control+Space` 进入随便问；设置页支持录制新组合键并保存后重新注册。
- 设置：录制快捷键、麦克风选择、交互声音、录音时静音、开机启动、Dock 显示、个人输出偏好。
- 托盘：左键打开 Hub，右键菜单触发三种模式和退出。
- 转写：真实麦克风录音需要用户手动确认。
- 粘贴：真实焦点输入框粘贴需要用户手动确认。

## 不写自动化脚本说明

项目规则默认不补自动化脚本，除非用户明确要求。本批用真实页面/桌面应用和构建结果验证。
