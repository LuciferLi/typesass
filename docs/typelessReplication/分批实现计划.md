# 分批实现计划

## 第一批：核心闭环增强（已完成）

目标：把 typesass 从单一悬浮转写工具扩展成 Typeless 风格桌面工具。

交付：

- Hub 窗口。
- 首页、历史、词典、设置。
- 语音输入、翻译、随便问三模式。
- 本地历史和词典。
- 默认快捷键。
- 基础托盘入口。

验收：

- 构建和打包通过。
- `.app` 启动成功。
- Hub 可打开。
- 悬浮录音条不常驻，快捷键触发才出现。

## 第二批：设置完整化

目标：补齐设置页体验。

交付状态：

- 可视化录制快捷键：已完成。
- 动态注册/注销快捷键：已完成，Rust 全局快捷键保存后立即重注册。
- 麦克风选择：已完成，依赖用户授权后显示真实设备名。
- 交互声音：已完成，开始/停止轻提示音。
- 登录启动：已完成，macOS 用户级 LaunchAgent。
- Dock 显示：已完成，Tauri `set_dock_visibility`。
- CSV 导入词典：已完成，同时支持 CSV 导出。

## 第三批：个性化与上下文（基础版已完成）

目标：让输出更接近 Typeless 的“按 App 和个人风格自动调整”。

交付状态：

- 前台 App 检测：已完成，macOS 通过 System Events 读取 frontmost app。
- 按 App 的输出风格配置：基础版已完成，前台 App 名称进入 AI prompt。
- 本地抽象偏好：基础版已完成，设置页支持个人输出偏好。
- 术语自动加入候选：延期，避免自动规则误收普通词。

## 第四批：账户、报告和高级能力

目标：补齐非核心商业产品能力。

交付候选：

- 用量报告。
- 配额展示。
- 账户页。
- 检查更新。
- 移动端入口占位。

当前自用版本不做支付和订阅。
