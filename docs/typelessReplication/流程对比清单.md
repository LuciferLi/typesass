# 流程对比清单

| 源流程 | 触发入口 | 前置条件 | 主路径 | 异常路径 | 目标流程 | 状态 | 差异 | 验证方式 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 语音输入 | `Left Ctrl + D` | 麦克风权限、已配置服务 | 按下开始 -> 说话 -> 再按停止 -> 转写/整理 -> 粘贴 | 麦克风失败、ASR 失败、粘贴权限失败、无输入焦点 | `Control+P` 同路径；失败时弹结果窗口 | done | 保留用户已有 `Control+P`，输入焦点不满足时不伪装成粘贴成功 | 构建 + 用户真实录音 |
| 翻译 | `Left Ctrl + T` | 有目标语言 | 按下开始 -> 说话 -> 停止 -> 翻译 -> 粘贴/展示 | AI 失败、目标语言缺失 | ASR 后 AI 翻译 | done | 技术平替 | 构建 + 用户真实录音 |
| 随便问 | `Left Ctrl + Space` | 有 AI 模型 | 按下开始 -> 说问题 -> 停止 -> 生成答案 | AI 失败 | ASR 后 AI 答案展示 | done | 不默认粘贴答案，显示 Hub | 构建 + 用户真实录音 |
| 查历史 | Hub 历史 | 有记录 | 进入历史 -> 筛选 -> 复制/重试/删除 | 无记录 | localStorage 历史 | done | 一致 | 页面操作 |
| 管词典 | Hub 词典 | 无 | 新词 -> 保存 -> 搜索/删除/导入/导出 | 空词、重复词 | localStorage 词典 | done | 增加 CSV 导入导出 | 页面操作 |
| 改设置 | Hub 设置 | 无 | 修改配置 -> 保存 -> 立即生效 | 配置无效、快捷键冲突 | localStorage + Rust 会话设置 | done | Key 不落盘，快捷键/桌面项即时同步 | 构建 + 页面操作 |
