# 技术平替决策

| 源能力 | 源行为要求 | 目标已有能力 | 平替方案 | 行为等价验证 | 风险 | 是否需用户确认 |
| --- | --- | --- | --- | --- | --- | --- |
| 系统级输入 | 当前输入框自动出现结果 | `pbcopy` + CoreGraphics | 写剪贴板后触发 `Cmd+V` | 手动聚焦输入框测试 | macOS 辅助功能权限 | 否 |
| AI 转写 | 快速语音识别 | Mimo ASR | `mimo-v2.5-asr` | 真实录音测试 | 外部服务速度与额度 | 否 |
| AI 整理/翻译/问答 | 文本后处理 | OpenAI 兼容 chat | 新增 `process_text` 命令 | 文本样例验证 | AI 模型名需用户配置或环境配置 | 否 |
| 历史保存 | 本地历史可筛选 | `localStorage` | 前端本地保存 | 页面操作 | 浏览器存储可被清理 | 否 |
| 词典 | 术语提升准确率 | `localStorage` + prompt | 词条注入 ASR/AI 提示 | 术语样例验证 | ASR 不一定完全服从 | 否 |
| 动态快捷键 | 设置页改键立即生效 | `tauri-plugin-global-shortcut` | Rust 注销旧快捷键后注册新快捷键 | `cargo check` + 真实快捷键 | 与系统/其他 App 冲突时会注册失败 | 否 |
| 开机启动 | 登录后后台可用 | macOS LaunchAgent | 写入用户级 `~/Library/LaunchAgents` | Rust 编译 + 用户系统验证 | 未安装到稳定路径时启动路径可能变化 | 否 |
| Dock 显示 | 用户可切换 Dock 图标 | Tauri app API | `set_dock_visibility` | Rust 编译 | macOS 行为由系统管理 | 否 |
| 托盘菜单 | 菜单栏入口 | Tauri tray | 程序化创建托盘图标和菜单 | `.app` 启动 | 图标由当前 App 自有资源生成 | 否 |
| 前台 App 上下文 | 按当前输入场景调整语气 | AppleScript/System Events | 读取 frontmost app 名称后注入 prompt | Rust 编译 + 用户真实录音 | 需要辅助功能权限或系统允许读取 | 否 |
| 个性化 | 按类别学习风格 | 本地设置 + prompt | 设置页保存个人输出偏好 | 构建 + AI 输出待用户确认 | 长期自动学习仍需设计 | 否 |
