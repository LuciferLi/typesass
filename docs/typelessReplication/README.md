# Typeless 功能级复刻

## 目标

把 Typeless 的核心行为复刻到 typesass：全局快捷键唤起、悬浮录音条、语音转写、可选 AI 润色、翻译、随便问、自动粘贴、历史记录、词典、设置、托盘/Hub 管理和基础统计。

本项目只做功能级复刻，不复制 Typeless 源码、品牌、图标、样式资产或专有文案。

## 来源

- 本机 Typeless：`v2.1.0`，通过 Computer Use 读取实际 UI。
- 公开资料：`https://www.typeless.com/` 与 Typeless macOS release notes。
- 目标项目：`/Users/lucifer/Documents/source/t/monorepo/aiTool`，Tauri v2 + Vite + TypeScript + Rust。

## 当前批次

当前已经完成核心闭环、设置完整化、上下文个性化、深色参考风格、桌面后台启动、结果兜底窗口、Keychain 安全保存、首页准备状态引导、typesass 品牌视觉收口、最终圆润动效抛光、误触保护、权限后的短录音自动粘贴验证、Typeless 风格托盘菜单和自动粘贴诊断日志。

已完成：

- Hub 窗口：首页、语音模式、快捷键、历史、词典、系统设置六个基础视图。
- 三种模式：语音输入、翻译、随便问。
- 口述润色：顶部快捷开关和设置页开关联动；关闭后口述只等待 Mimo ASR，直接粘贴原始转写。
- 历史记录：本地保存、筛选、复制、重试、删除。
- 词典：新增、搜索、删除、全部/手动筛选、CSV 导入导出，作为 ASR/AI 的术语提示；自动词条生成前不展示自动筛选入口。
- 设置：Mimo Keychain 保存、模型配置、动态快捷键、麦克风、交互声音、录音时静音、开机启动、Dock 显示、翻译目标语言、历史保存策略、个人输出偏好。
- 保留已有悬浮胶囊和自动粘贴。
- 结果兜底：无辅助功能权限或系统粘贴命令失败时，不伪装成已粘贴，改为弹出结果窗口供复制。
- 权限准备：设置页可主动请求麦克风授权，辅助功能可一键打开系统设置。
- 权限反馈：打开辅助功能设置后，Hub/结果窗口会进入等待授权检测态；授权成功后自动刷新。
- 误触保护：录音低于 800ms 时直接提示重新说，不请求 Mimo ASR/AI，不保存历史。
- 体验反馈：最近结果和历史记录展示录音、转写、AI 处理耗时；历史可展开查看原始 ASR 文本。
- 品牌资产：产品名统一为 typesass，使用切图后的圆润 Logo，桌面 App 图标已更新。
- 图标体系：Hub 导航和操作按钮统一使用 IconPark 图标。
- 交互动效：悬浮录音条按真实麦克风音量刷新波形，录音态有呼吸反馈，错误态有轻震反馈；Hub 页面切换、卡片进入、分段切换和结果窗口均有轻量过渡。
- 桌面端：Rust 动态注册快捷键、托盘左键菜单、前台 App 读取、用户级 LaunchAgent；启动后默认不弹 Hub，不在 Dock 常驻。
- 真实闭环：辅助功能授权后，已用 TextEdit 聚焦输入框验证 `Control + P` 开始、短录音、再次 `Control + P` 停止、Mimo 转写、AI 整理、自动粘贴和历史耗时记录。
- 诊断日志：Hub 新增“诊断日志”栏目，记录快捷键、录音、ASR、AI、剪贴板、辅助功能、目标 App、粘贴方式和发送前后前台 App；不保存用户转写正文。
- 录音可见性：Hub 已打开时，按快捷键开始录音不再隐藏 Hub、不弹出悬浮胶囊、不切走前台焦点；从 Hub 发起的录音完成后不自动粘贴，只更新最近结果和历史记录。外部输入框发起的录音仍会在最终粘贴前临时隐藏 typesass 窗口，避免文本粘贴回本应用。

## 当前风险

- Typeless 是商业软件，源代码不可用，本轮按行为观察和公开资料推断，不做源码级复制。
- Mimo Key 已改为 macOS 钥匙串保存，不写入 localStorage 或配置文件；浏览器预览模式无法检测钥匙串，需在真实 `.app` 中确认。
- macOS 自动粘贴受辅助功能权限和系统焦点恢复影响；授权后已在 TextEdit 聚焦输入框验证成功，当前策略会在最终粘贴前隐藏悬浮条、结果窗口和 Hub，再发送粘贴指令，并在诊断日志中记录目标 App、粘贴方法和发送前后前台 App，便于定位偶发失败。
- 托盘菜单左键弹出菜单已接入；菜单栏彩色 Logo 受 macOS 菜单栏尺寸和系统图标缓存影响，仍建议用户本机目视确认。
- 登录、账户、订阅、移动端同步属于第四批候选，不作为第一批交付门。
