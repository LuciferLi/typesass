# 自动化测试

## 2026-07-24 批次 1-3

结论：未新增自动化测试脚本。

原因：

- 项目规则默认不编写、补齐、优化或规划自动化测试脚本，除非用户明确要求。
- 当前核心能力涉及 macOS 全局快捷键、麦克风授权、辅助功能权限和系统托盘，自动化脚本无法完整替代真实桌面验证。

替代验证：

- `npm run build`：通过。
- `cargo check --manifest-path src-tauri/Cargo.toml`：通过。
- `cargo fmt --check --manifest-path src-tauri/Cargo.toml`：通过。
- `npx tauri build --bundles app`：通过。
- `.app` 启动验证：通过。

剩余风险：

- 真实快捷键、真实录音、真实自动粘贴、开机启动和 Dock 切换需要用户在本机操作确认。
